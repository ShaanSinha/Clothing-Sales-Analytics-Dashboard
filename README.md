# Clothing Sales Analytics Dashboard

##  Project Overview

This project analyzes clothing store sales data using Power BI, SQL, and Python.

The dashboard provides insights into:

- Total Revenue
- Total Orders
- Total Customers
- Total Products
- Revenue by Category
- Revenue by City
- Top Selling Products

##  Tools Used

- Power BI
- SQL
- Python
- Excel

##  Dataset

Dataset contains:

- Customers
- Orders
- Products
- Sales

##  Dashboard Features

- KPI Cards
- Interactive Category Filter
- Revenue Analysis
- Product Performance Analysis
- City-wise Revenue Analysis

##  Key Insights

- Women's Wear generated highest revenue.
- Delhi is the top revenue-generating city.
- Top-selling products vary by category.
